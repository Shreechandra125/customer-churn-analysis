
# 📊 Customer Churn Analysis Dashboard

## Overview

This project analyzes customer churn data to identify factors that cause customers to leave a service.
It uses **exploratory data analysis and interactive visualization** to support data-driven retention strategies.


## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit


## Dataset

**Telco Customer Churn Dataset (IBM)**
File: `WA_Fn-UseC_-Telco-Customer-Churn.csv`


## Key Features

* Interactive Streamlit dashboard
* Churn rate KPI
* Contract-based churn analysis
* Dynamic filtering and charts


## Key Insights

* Month-to-month contracts have the highest churn
* Long-term contracts improve retention
* Higher charges increase churn risk


## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
